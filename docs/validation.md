## 验收方式

1. 初始化权限、共享选择和必要的开发诊断在任务开始前完成。
2. Agent 开始后，不从 Mac 串口注入鼠标或键盘；Mac 只读取 App 私有诊断。
3. 记录实际任务、动作是否执行、当前截图、模型调用、ACK 和最终状态。
4. 完成任务必须有新的可见结果，另一次完成校验也必须通过；不能只看 ACK、连接状态或期望答案。
5. 失败记录保留在私有 `.local/`，不公开个人屏幕、聊天、API Key、配对信息或设备序列号。

## 尚未证明的能力

- 任意 App、复杂多步骤任务、拖动和滚轮的稳定成功率。
- 新 harness 对定位失败、错误计算结果的实机恢复效果。
- 锁屏后的恢复；遇到锁屏必须停止，不自动解锁。
- iPhone 直接通过 USB 给这块 C3 供电的线材组合。当前验证供电来自独立 USB；运行控制链路是 BLE。
- 长期无人值守、网络/蓝牙反复中断后的稳定性、发热及功耗。

因此目前应把它作为可开发和验收的实验原型，不能宣称完整需求已稳定完成。
