### 真实任务复测与诊断（build 13–17）

用户报告任务无法完成后，在同一手机和 C3 上复测。决策模型为
`qwen3.8-max`，辅助视觉为 `qwen3.8-flash`；Key 保留在手机内，未导出。
各任务由手机 App 独立取屏、调度和下发输入，Mac 仅提交完整任务及读取诊断。
安装后的系统共享确认在任务开始前完成；没有从 Mac 代替 Agent 点击任务目标。

本轮修复 App 的两个多余帧等待，增加带上下文的超时、取屏状态/时间诊断，
加入有独立焦点检查的 Clear 动作，提示模型不重复点击失败的小叉号。
build 17 另外区分清空与输入检查条件，并对辅助视觉无效/截断 JSON 最多重试一次。

53 秒、辅助视觉约 50 秒，说明模型往返和错误拒绝本身也显著拖慢任务。

## 本轮输入核验

整段文本输入前由另一轮视觉请求检查真实输入位置；计算器须显示精确的 `0`，没有小数点或待算表达式，并给出覆盖完整显示行的裁图范围。手机本地 OCR 检查这个区域：识别到 `0.27` 等残留内容会拒绝输入；OCR 无结果或置信度不足时，独立读取显示区域，不能将空 OCR 当成零。核验后显示区域若变化则不输入。拒绝次数有上限，避免无限重试。

合成图回归发现 Apple Vision 可能漏掉单独的 `0` 或 `0.`，因此这类结果走“不确定”分支，必须另行读图；没有声称 OCR 能可靠区分所有字体的小数点。OCR 在工作线程运行，首次加载模型期间仍能处理取屏、停止请求和任务时限。

新增“开始屏幕共享”入口和等待选择状态诊断；共享取消、失败或结束会清理旧帧与排队任务。共享会话存活时复用，不要求每个任务重新确认。无会话时 App 可主动调出系统选择器；系统共享选择仍需在可见界面完成。

## 验收方式

1. 初始化权限、共享选择和必要的开发诊断在任务开始前完成。
2. Agent 开始后，不从 Mac 串口注入鼠标或键盘；Mac 只读取 App 私有诊断。
3. 记录实际任务、动作是否执行、当前截图、模型调用、ACK 和最终状态。
4. 完成任务必须有新的可见结果，另一次完成校验也必须通过；不能只看 ACK、连接状态或期望答案。
5. 失败记录保留在私有 `.local/`，不公开个人屏幕、聊天、API Key、配对信息或设备序列号。

## 尚未证明的能力

- 任意 App、复杂多步骤任务、拖动和滚轮的稳定成功率。
- 新 harness 对定位失败、错误计算结果的实机恢复效果。
- 锁屏后的恢复；遇到锁屏必须停止，不自动解锁。
- iPhone 直接通过 USB 给这块 C3 供电的线材组合。当前验证供电来自独立 USB；运行控制链路是 BLE。
- 长期无人值守、网络/蓝牙反复中断后的稳定性、发热及功耗。

因此目前应把它作为可开发和验收的实验原型，不能宣称完整需求已稳定完成。
