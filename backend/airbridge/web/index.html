手机如何连接

  1. 手机、C3、Mac 连接同一局域网（C3 需 2.4 GHz）；Mac 保持运行。
  2. iPhone 蓝牙连接 C3 AirBridge。开启辅助触控，手机保持解锁。
  3. 控制中心 → 屏幕镜像 → C3 AirBridge。
  4. 确认上方显示“画面更新中”，再输入任务。

画面过期时停止盲点。若启用了 USB 诊断备用观察，画面来源会明确标注；所有操作仍经 C3 蓝牙。
